# 报告前离线分析

本目录仅使用已有合并记录，未调用模型。运行：

```bash
export NLTK_DATA="$PWD/ifbench/.nltk_data"
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python scripts/offline_report_analysis.py
```

结果见 `analysis.json` 及各 CSV。脚本核对合并后的 2080 条身份、169 个替换身份及既存汇总，并对 5 条案例回答重新评分。输入见原报告素材的 `source_manifest.json`。

## 1. 配对统计检验

使用双侧精确同源组符号翻转检验：每个同源组内的配对差异整体交换，其他题各自为一组；统计量为配对差异和的绝对值。此检验依赖零假设下组内条件标签可交换，已识别同源组可能不完整。对两个模型的六个 B1/B2/B3 对 B0 比较进行一次 Holm 校正；四个 B2 对 B1/B3 的探索性比较单独校正。所有新增检验和这两个校正族均为事后确定，不是冻结时预注册的显著性检验；不能将它们表述成控制了所有研究比较的整体错误率。

| 模型 | 对比 | 配对数 | 差异（百分点） | 原始 p | Holm p |
|---|---|---:|---:|---:|---:|
| gpt-4.1 | B1-B0 | 258 | +3.10 | 0.30200 | 0.42205 |
| gpt-4.1 | B2-B0 | 258 | +9.69 | 0.00007 | 0.00042 |
| gpt-4.1 | B3-B0 | 257 | +5.84 | 0.01067 | 0.03202 |
| gpt-4o | B1-B0 | 255 | +3.53 | 0.21102 | 0.42205 |
| gpt-4o | B2-B0 | 258 | +10.08 | 0.00016 | 0.00078 |
| gpt-4o | B3-B0 | 255 | +7.84 | 0.00082 | 0.00329 |
| gpt-4.1 | B2-B1 | 258 | +6.59 | 0.00948 | 0.03790 |
| gpt-4.1 | B2-B3 | 257 | +3.89 | 0.14331 | 0.28661 |
| gpt-4o | B2-B1 | 255 | +6.67 | 0.01862 | 0.05587 |
| gpt-4o | B2-B3 | 255 | +2.75 | 0.31050 | 0.31050 |

B2、B3 对 B0 在各自模型中校正后 p < 0.05，B1 对 B0 未达到该阈值。探索性 B2 对 B1 仅 gpt-4.1 校正后 p < 0.05；gpt-4o 为 0.05587。B2 对 B3 未检出差异，不能视为等效。原有 bootstrap 区间未做多重校正，与此检验的 p 值并非同一方法计算。

## 2. 缺失值稳健性

`robustness.csv` 列出全部对比。B2−B0 的可用配对、四条件完整、缺失计失败分别为：gpt-4.1 +9.69、+9.73、+9.62 个百分点；gpt-4o +10.08、+10.63、+10.00 个百分点。各对比的点估计方向保持一致；这不代表检验显著性在所有口径下均已验证，也不能排除非随机缺失造成偏差。缺失计失败仅为假设情景，不改写原始数据。

## 3. 约束类别

`categories.csv` 使用原始 instruction ID 的前缀分组，按约束计数；双约束题贡献多条，不能视为相互独立。类别为探索性描述，类别之间题目组成不同，不做因果推断。例如 gpt-4.1 的 words 类 B0 失败 46/82，B2 失败 39/82；gpt-4o 的 count 类 B0 失败 14/55，B2 失败 7/55。custom 和 repeat 分母仅 10、9 左右，不宜对其排序作强结论。

## 4. 案例与审核样本

`cases.csv` 保留原文和匹配的记录路径。重评分确认：gpt-4.1 item 173 B0 失败而 B2 通过；item 287 B0 通过而 B1 失败；gpt-4o item 247 B2 规则通过，其人工确认内容标签为 partial。案例是目的性选取，不能估计发生率。

`review.csv` 比较生成时预抽的 40 题与其余题的 **strict 规则通过率**，不是现行内容审核分母。该 40 题子集在八个模型与条件组合中的 strict 通过率均高于其余题，仅说明规则通过率，不能证明题目本身更容易。现行内容审核已覆盖全部 260 题、2080 条，见 `RESULTS_TABLES.md` 表 5。
