## 报告可用结论

- B2 与 B3 相对 B0 的 strict 配对提升在两个模型上均为正，95% 区间不含零；B1 区间包含零。
- 探索性比较中 B2 优于 B1；B2 与 B3 的区间包含零，不能声称 B2 显著优于 B3。
- B2 的修复率分别为 26.4% 和 32.4%，同时存在 5.1% 和 6.8% 的规则退化。
- 全量内容审核中 2046/2072 条已判定回答为 complete；818 条内容完整但 strict 失败；7 条 partial 与 12 条 incomplete 仍 strict 通过。规则遵循与内容充分性应分别讨论。
- 8 条无法判定（均为 item 147 的 Azure 内容过滤连锁）。内容标签接近天花板，不能据此证明反馈不会损害内容质量。
- 盲审后的内容完成率在 B1/B2/B3 上与 B0 几乎相同；配对差异的 95% 区间均含零，Holm 校正后不能拒绝无变化。反馈改善的是约束遵循，不是原任务完成率。

## 图注

- 01_prompt_accuracy：strict 与 loose 提示级通过率；柱上标明通过数/可评分数，纵轴从零开始。
- 02_paired_effects：配对 strict 差异与未校正 95% bootstrap 区间；下方两组对比为探索性。
- 03_repair_regression：修复和退化的分子/分母；两种率的分母不同。
- 04_content_review：内容标签计数和 strict 交叉表；2080 条覆盖全部 260 道测试题。
- 05_content_accuracy：盲审后各条件内容完成率（complete/已判定）。
- 06_content_paired：内容完成率的配对差异与未校正 95% bootstrap 区间。
